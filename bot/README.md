# Telegram бот (@bayan_mxik_bot)

Штрих код (GTIN) ёки 17 хонали МХИК кодини юборсангиз, tasnif.soliq.uz базасидан маълумотини топиб,
BAYAN MEDICAL каталоги билан солиштириб беради. Фақат Python 3 стандарт кутубхонаси ишлатилади.

## Серверда

Бот сайт билан бирга серверга чиқади (bayan-erp репозиторийсидаги `deploy/`): `main` тармоғига
қўшилган ўзгариш кейинги деплойда серверга тушади ва бот қайта ишга тушади.

- Токен репозиторийда сақланмайди. У bayan-erp репозиторийсининг `TELEGRAM_BOT_TOKEN` номли
  GitHub secret'ида туради ва ботга `BOT_TOKEN` ўзгарувчиси сифатида берилади.
- Каталог шу репозиторийдаги `catalog.json` файлидан ўқилади (`CATALOG_FILE`).
- Telegram бир вақтда фақат битта нусханинг ишлашига рухсат беради: сервердаги бот ишлаётганда
  компьютердаги `start.bat` ёпиқ бўлиши керак.

## Компьютерда (синов учун)

`bot.py` ёнига `token.txt` файлини қўйиб, ичига BotFather берган токенни ёзинг ва
`python bot.py` буйруғини ишга туширинг. `token.txt` репозиторийга қўшилмайди.
